# 雪山牧场：大色块油画环境与资产版

入口：http://127.0.0.1:5405/?scene=alpine

## 游玩

- WASD / 方向键移动；Shift 冲刺；空格跳跃；鼠标转向，滚轮调整跟随距离。
- E：领取饲料、开关牧场门、喂牛、溪畔打卡、交回篮子。
- R：重新巡场；V / 右上角按钮：全景观察和人物跟随；Esc 释放鼠标。
- 顺序：小巴旁领饲料 → 找到三头牛 → 返回小巴交回篮子。溪畔观景是可选支线。
- 默认高质量；?scene=alpine&quality=low 降低草丛实例数、分辨率并关闭体积光。

## 尺度与接触

一个世界单位是一米。人物碰撞身高 1.8 米，含帽子的可见模型约 2.02 米；牛可见高度约 1.5 米；小巴长 6.2 米；围栏高约 1.1 米。复用原项目的人体骨架、动作、脚底定位和 Rapier 胶囊控制器。

地面渲染、草根、牛的位置和 Rapier 高度场读取同一份地形。树有实体圆柱树干、根部、分枝与针叶簇；树干碰撞使用同一棵树的位置、半径和高度。门的可见转轴和碰撞体同步旋转。桥面、栏杆、石头、小巴和牛也有碰撞。

草簇使用原项目的油画笔触实例系统，按生境噪声分出低矮贴地草、宽叶草本和局部高草，笔触长度约 0.07–0.59 米。宽叶斜向展开、草根错开，避免整齐扇形；实际垂直高度随叶片倾斜、风和接触变化。人物附近的草会向外拨开，最近 16 段脚步轨迹逐渐恢复。它是 GPU 接触响应近似，不是每片叶子的刚体模拟。

溪流拆成主流、汇入主流的侧汊与露滩，河床雕刻在同一高度场内。水位使用单调坡降曲线，缓潭与较陡浅瀬交替。水面三角形按有符号水深裁剪，只存在于湿河槽，避免整张矩形平面漫过草地。渲染和涉水使用同一水位/深度/速度场；笔触粒子沿速度场积分，八块实体河石共享绕流与尾沫位置。岸边按水深透明过渡到湿砂。此为预设稳态流场与接触表现，不是求解质量守恒的浅水方程或完整流体模拟。约 6700 个立体小砾石、额外大石块和五组冷暖石色构成裸露河滩；湿润边缘变暗。连续水面、顺流宽笔触、轻微起伏和脚步涟漪提供流动感，涉水后切换慢行。水面只在地形上方显示，桥上不会触发涉水。桥跨越整个砂石河床，两端斜坡连接陆地。水的表现采用实时着色与阻力近似，不是流体求解器。接入原项目的阴影与体积光，并加入随风飘动的草籽。

## 路边建筑与落地

按追加照片，在小巴附近路西加入石墙木构小屋、坡屋顶、烟囱轻烟、门廊台阶、独立木棚与院栏，周围十六棵云杉按高低、前后错落布置，保持道路和门前畅通。主屋约 7.4 × 6.4 m，门高 2.04 m；木棚约 4.1 × 3.1 m。

牧场共有九头牛：三头保留喂食互动，另外六头在道路两侧吃草、甩尾并带实体碰撞。已删除左侧任务栏，保留接近互动、短时提示及 R 重置。

`placement.js` 对完整占地网格采样地形。每栋建筑有独立地坪标高，基础底部埋入占地最低点以下 0.15 m，并使用相同体积构建碰撞。门廊柱、台阶、院栏柱和座椅腿分别贴地；院栏横杆连接两端实际标高。禁止把附属物直接沿用主屋原点高度。新参考保存在 `public/alpine/references/roadside-cottage.png`。

## 参考图还原方式

新疆竖幅油画决定山势、环境、配色和布局；追加的秋日森林与极光截图决定大色块、宽长笔触和成组明暗。`public/alpine/reference.png` 保存原图，两张笔触截图在 `public/alpine/references/`。远景生成记录见同目录 `ASSETS.md`。

12 张独立资产图及提示词的入口是 `/alpine/assets.html`。最终版在 `public/alpine/assets-v3/` 和 `output/alpine-assets-v3/production/`；目录沿用资产迭代编号，实际风格修订标识为 `large-flat-brush-v4`。首轮细笔触结构稿单独保留在 `output/alpine-assets-v3/structure/`。第 08、09 张地表图片已经接入 `land.js`，以固定世界坐标采样低层色彩，再叠加实时油画笔触；其他图片用于三维造型参考，不冒充可绕行的模型。

远山已移除全景图片和透明绘景平面。mountains.js 用连续三维高度网格生成山峰、连接山脊、山谷与周围丘陵；雪线由高度和坡度决定，笔触固定在三角面上并沿坡面走向排列。山体有真实深度、遮挡和视差，不再依靠图片边缘透明渐变接续。约 16 万个顶点、10 万个固定表面笔触。远山位于当前牧场可游玩边界之外，暂未加入登山关卡碰撞。

## 修改入口

- `config.js`：种子、场景坐标、道路与河道、互动对象位置。
- `land.js`：地形、道路/河岸掩码、地面油画底色、高度场。
- `landscape.js`：天空与环境组合；`mountains.js`：连续三维山脉、雪线和固定表面笔触；`forest.js`：真实树干、根系和针叶簇。
- `environment.js`：风、脚步历史、涉水判定与草籽；`meadow.js`：生境草簇与接触响应；`stream.js`：水面、顺流笔触与立体砂石。
- `cottage.js` / `placement.js`：路边建筑、独立地坪与贴地基础；`cow.js`：牛的连续躯干、腿部关节、蹄、头颈、角、尾；`vehicle.js`：小巴；`bench.js`：完整木结构座椅；`props.js`：组合、动作、道具与碰撞。
- `game.js`：任务状态、接近交互、开门、重置、中文 HUD。
- `main.js`：原角色/相机/物理/油画渲染组合，质量档位与全景机位。

## 构建与回归

默认构图使用 42° 垂直视角、13 米跟随距离、0.18 弧度俯角，人物约占画面高度 20%；滚轮可在 2.8–26 米间调整，相机仍保留地面与障碍避让。秋日森林默认跟随距离 11.8 米。牧场保留暖光及冷色阴影，以 0.00065 的基础空气密度和 0.0026 的贴地雾密度形成清晨薄雾，光束强度为 0.16。沿视线做六次地形高度采样，雾在离地 16 米的高度尺度内逐渐消散，12–48 米距离间平滑起雾；固定世界坐标的疏密变化让雾融入树脚与河谷。山脚使用同一雾色，向雪峰平滑减弱，保留远山的颜色和轮廓。画布经纬纹固定在屏幕空间并按像素比缩放，`?canvas=0` 可关闭；纹理不随时间滚动。
