## 页面实现状态（2026-11-17）

已在四条区域连接路接入约 240 米的程序化过渡带。入口沿用原场景的地面采样，逐渐进入共用谷地；中央地形和物件使用同一套参数，在两侧各自的局部原点下生成。进入目标侧时转换角色、速度与相机的相对坐标，保留步行动画相位和时间，不再使用步行截图淡出。

- `src/travel/boundary.js`：混合地表、道路、立体草簇、树干/枝叶、石块、农舍、石墙、桥梁、流动水面与远处体积山坡。地形与桥面碰撞来自可见网格。
- `src/travel/walk-connections.js`：接入原路、区域环境权重、碰撞过滤、边界安全落脚与跨区坐标。
- `src/travel/terrain-stitch.js`：按真实世界位置裁掉过渡带覆盖范围内的旧表面，保留范围外原场景；地面不做整区透明或噪点淡出。
- `src/boot.js`：在共用中段切换区域，目标首帧准备完成后才移除原画布；加载提示缩为角落文字。
- 直接体验入口：`?scene=alpine&trail=golden`、`?scene=village&trail=bridge`、`?scene=autumn&trail=pass`、`?scene=aurora&trail=snowmelt`。入口参数只在初次进入时使用，随后从地址删除，防止后续传送误用。
- 交互：草簇有风与近身压低效果；水面色块沿河流方向移动；树干、主要石块、墙、房屋与桥有实体碰撞。

实现边界：这版仍使用分区的物理世界和渲染器，交界采用相同中段的坐标接续；尚非整个地图共用一个持续运行的物理世界。首次跨区可能短暂停步等待构建。当前各区高度是局部坐标，通过浮动原点对齐中段，不能解释为已经铺设了连接全部真实海拔的公里级山路。天空与光照在接近中段时渐变，独立区域的完整日夜时钟尚未统一。

### 地面穿插修复

最初的整区噪点淡出会让旧地面仍然可见，而人物已切到新碰撞面；仅沿路线走通的测试没有覆盖这个视觉错误。现已移除该淡出和无碰撞的装饰性山坡。过渡带使用 2 米三角网格，四边逐渐接回原地形；物理碰撞、角色高度查询与资产落点均读取同一组实际网格顶点。接缝覆盖范围内的旧地面、原有草簇和原有物件按真实世界位置裁掉，避免上下两层地面同时显示。

新增 `tools/terrain-contact-check.mjs`：从真实渲染深度纹理还原地面高度，与 Rapier 射线碰撞比较，覆盖八个入口的路中与左右路肩；采样时暂时关闭笔触实例以排除树冠遮挡，另对照完整实机截图。包含金草缓坡左右接缝的真实步行检查。证据输出为 `shots/terrain-contact/`，不上传运行产生的临时文件。

验收脚本：`tools/walk-worlds-check.mjs` 检查八向出发路；`tools/boundary-check.mjs` 检查四段共用核心的高程、相机接续，以及跨区后继续走完目标半段；`tools/world-map-check.mjs` 检查传送、进度和窄屏地图。实机证据存于忽略跟踪的 `shots/boundaries/`。

## 设计判断

四个区域属于同一片可旅行的山地。交界是有长度、有高差、可回头的地带，玩家先看到目的地的线索，走过混合环境，再进入区域主体。保留蓝披风草帽角色、真实比例、宽笔触厚涂和已有区域身份。

四段过渡沿既有环路布置：雪岭—牧场—麦田—秋林—雪岭。溪流只在地形允许的下坡方向连通；不能为了把图接起来，让水跨越山脊流向更高处。

以下距离、密度与坡度均为设计目标，需要落地时用真实端点采样校核，不是已实现或已测得的性能。

## 01 雪线融水谷：极光雪岭 ↔ 雪山牧场

- 功能：沿融水谷升降，提供牧场和雪岭之间的高程与气候变化。
- 顺序：低矮牧草和多色砾石 → 金草、裸岩、稀疏云杉 → 阴坡残雪与雪松 → 雪岭主体。草和雪沿坡向、遮阴和凹地呈岛状交叠。
- 核心地标：带裂缝的巨石；辅助体块为溪谷与木桥。道路绕石后才展开雪岭视野，桥不作为整幅画面切换线。
- 局部混合植被带约 180–260 米；总连接路长度由真实高差决定。雪岭现有局部坐标高度约 220 米，不能直接把它当成与牧场相邻的同高路面。
- 水体：下游较宽的浅滩、上游碎石急流，河床有灰蓝、赭褐、乳白卵石；路面和桥面保持干燥，水位低于两岸与桥面。
- 交互：草受角色挤压，积雪区出现足迹，水声随溪流距离变化，木桥脚步声与石路区分。

## 02 金草缓坡：雪山牧场 ↔ 柏树麦田

- 功能：从放牧地进入耕作地，作为首个实施样段，先解决白天地形和材质连续性。
- 顺序：牧草和小群牲畜 → 干草、灌木和矮石墙 → 麦穗与橄榄树篱 → 柏树、赤陶屋顶村庄。
- 核心地标：弯道旁的小石屋；辅助为低矮挡土墙和灌溉沟。玩家在牧场侧就能看见房顶和两株柏树。
- 过渡带约 140–200 米；弯道内外同时混合绿草与金草，田界用地形和矮墙表达，禁止直线换色。
- 草高目标：常被踩踏的路肩 0.05–0.12 米，牧草 0.15–0.35 米，未放牧种子草 0.35–0.65 米，成熟麦穗 0.75–1.05 米。按块群生，留出裸土、低草和高草间隙。
- 交互：篱墙存在真实碰撞；麦穗受风和角色扰动；灌溉沟过路处有涵洞或踏板；牲畜活动区避开主路。

## 03 林缘石桥：柏树麦田 ↔ 秋日森林

- 功能：从开阔农田收束到林荫步道，溪流承担地理边界，桥承担导航地标。
- 顺序：麦茬与橄榄篱 → 草地、散落阔叶树和落叶 → 山毛榉/桦树混交 → 秋林主体。
- 核心地标：低矮单孔石桥；辅助为溪岸和两侧混交林。桥净宽约 3 米，桥栏高约 0.9 米，入口两侧留出可绕行的浅坡。
- 过渡带约 120–180 米；林缘呈凹凸树群，远处树冠先于树干出现，落叶延伸到田边，麦茬也可进入疏林空地。
- 光照：同一太阳方向；树冠遮蔽产生局部明暗，雾主要停留在林内低处，不能在桥中央出现整屏灰蒙变化。
- 交互：落叶继续沿用秋林现有行为；桥、桥栏、岸石均有匹配碰撞；流水绕桥墩、岸石分流，湿润石面有压暗笔触。

## 04 落叶松山口：秋日森林 ↔ 极光雪岭

- 功能：沿盘山路跨越林线，承担四段中最明显的气候与光色变化。
- 顺序：阔叶秋林 → 金色落叶松与深绿云杉 → 霜草和阴坡残雪 → 雪岭。
- 核心地标：倾斜岩肩围出的山口；辅助为落叶松树群和远处雪峰。S 弯组织视线，入口能看见山口，转弯后才显露雪岭全貌。
- 局部过渡带约 200–300 米；若高差不足以在目标坡度内接上，增加真实盘山路，不能用短陡坡或瞬移消化高差。
- 光色：交界共用一套天空和太阳。山口因背阴偏蓝，林间可保留暖色灯光。极光只作为远处高空的微弱目的地线索；强极光应由共同的夜间时段驱动。
- 概念图展示暮色美术方向，不代表可在同一世界时刻从白天一步跨到黑夜。若保留各区独立昼夜，必须有明确的时间推进机制，不能称为自然的连续光照。
- 交互：逆风、针叶摆动、枯叶减少、雪粒和足迹逐渐增多；高处真实护栏只设在危险路段。

## 共同空间规则

1. 主路净宽 2.8–3.6 米，弯处和桥口适当放宽；人体、门洞、桥栏、树干都按米制开发。角色保持 1.8 米，不靠缩放角色掩饰环境比例。
2. 一般步行纵坡目标不超过 14%，短距离可到 22%；不以控制器“能爬上去”作为自然道路的标准。高差为 Δh 时，主路水平长度至少为 |Δh| / 0.14，另加弯道余量。例如 200 米高差需要至少约 1.43 公里水平长度，不能塞进 200 米边界带。
3. 每个连接段使用共同世界坐标中的入口/出口位置、切线、道路宽度、地面横断面；局部场景坐标可通过刚体变换映射，不能仅沿用各场景 z=±150 的触发点。
4. 连接曲线的两端高度与地形一致，切线连续。先生成路基、河床和坡面，再覆盖笔触与植被；渲染网格和物理碰撞来自同一高度数据。
5. 雪、草、裸土、落叶以多尺度斑块混合，结合坡向、湿度和人为使用分布。大色块承担结构，小笔触只补近景；不能满屏同尺寸草簇或用密集噪点替代造型。
6. 树群用高低错落的簇群和空地组织。保留可见树干、根部和接地阴影；建筑基础、石墙、路肩逐点贴合地形。
7. 山口和林缘让目的地逐渐显露。遮挡只用于合理组织视野，所有区域仍允许回头；不能用不可穿越的装饰墙伪装通路。

## 对现有代码的落地要求

当前 `src/boot.js` 步行切区会截图、销毁旧世界、创建新世界，再把角色放到目标路径上；`src/travel/walk-connections.js` 则分别在每个区域独立规划本地道路。这能完成通行，但没有共享的几何边界，因此截图淡出无法消除空间跳变。

实施应按以下顺序进行：

1. 先给牧场—麦田连接段定义共同世界中的两个端点和一条共享中心线，输出俯视图、纵断面和两端反向实机视角。采样实际高程并校验坡度。
2. 把连接带作为持续存在的独立区块，先载入相邻区域。角色、物理世界、相机和连接段地形在步行过程中持续存在；区域内的内容可流式加入或移除。
3. 实施共享边缘网格/高度数据、同一材质混合权重与实例散布规则。重复地形只保留一份，避免共面闪烁和双重碰撞。
4. 连接带内共用天空、太阳、曝光和雾参数。环境声和区域氛围随世界位置平滑混合，双向行走得到相同结果；时间性参数由共同世界时钟控制。
5. 连续步行不依赖全屏截图淡出。驿站快速传送可继续使用独立过场，避免把快速传送和实际步行混为一种机制。
6. 首段验收后再实施石桥、融水谷与盘山口。每段对照概念图还原可见形体，图片本身不得替代可接近的山体、桥、房屋或树林几何。

## 验收镜头与通过条件

- 八个方向各走一次：沿四条连接段往返，进入中部后立即回头、转动镜头、停留再走，不应出现地形或光照突变。
- 在连接段前、中、后各拍一张相同焦段的角色视角；转弯前后能通过同一地标确认位置，道路宽度、河流方向和远山遮挡关系稳定。
- 角色不传送、不重置速度；碰撞与可见地面吻合；相机不会突然换朝向或拉远。坡度、道路净宽与接地误差通过数值采样验证。
- 检查水体纵坡、桥面高程、草高层级、树根接地、建筑地基和左右岸材质过渡；不存在水面矩形硬边、悬空基础和断裂河床。
- 第一轮只认“代码实现后的实机录像”为连续性验收证据，概念图和加载测试均不能替代。
