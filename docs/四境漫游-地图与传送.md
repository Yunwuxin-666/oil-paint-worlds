# 四境漫游 · 地图与传送

北部极光雪岭、东部雪山牧场、南部柏树麦田、西部秋日森林围绕中央河谷形成环线。地图为区域导览示意，不是等比例的场景测绘；四区由步行连接道相连，驿站提供快速传送。

## 步行连接

新增雪岭 ↔ 牧场 ↔ 麦田 ↔ 秋林 ↔ 雪岭的八条有向连接道。沿途路牌显示目的地和剩余路程；道路基于同一地形高度与物理实体进行寻路，绕开树干、房屋及不可行走的坡面。

沿连接道走到末端时，无需打开地图或按传送键，会在当前页面加载相邻区域，并落到对方连接道的入口处；保留相对镜头角度、视距、行走输入及已有活动进度。邻区脚本预先加载，角色资源缓存，过渡时保留上一幅画面，切换完成后渐隐。此实现为分区加载和画面过渡，不是四个地区同时驻留的单块地形。

原场景按 X/Z 范围或离路距离触发的回出生点规则已移除。只有落水或掉到地形下方才恢复到最近的安全位置；R 重置操作仍按原场景定义执行。

场景入口改为可重复创建的 `startWorld()`。退出时中止键盘、鼠标、界面和 Patch 消息监听，停止渲染循环，释放物理世界、纹理、阴影与后处理目标和 WebGL 上下文。视角输入绑定到持续存在的视口，步行跨区保持鼠标锁定。

`src/travel/walk-connections.js` 管理道路和跨区检测；`src/travel/lifecycle.js` 管理退出清理；`src/boot.js` 管理同页场景加载。

- `public/world-map-prompt.txt`：最终图像提示词。

## 操作

点击左下角小地图或按 M 展开地图；点击地图区域或目的地名称，点击「传送至…驿站」。按 M / Esc 收起。地图展开时暂停人物输入并释放鼠标锁定，收起后恢复。

每个区域的起点前方约 10 米、道路一侧放置实体驿站。近处显示 G 提示，按 G 打开地图。驿站有落地石环、带碰撞的木柱、横梁和缓慢浮动的光标；各组件采样当地地面高度。传送后人物落在驿站入口附近，按当地地形重新放置物理胶囊，避免悬空和自动循环传送。

同一标签页通过 sessionStorage 保留采色、画作、喂食与牧场门状态。R 仍由各场景控制重置。地图的白色箭头表示人物在当前区域中的相对位置和朝向。

## 代码

| 文件 | 职责 |
| --- | --- |
| `src/travel/regions.js` | 四区名称、图上坐标、连接关系 |
| `src/travel/world-map.js` | 小地图、选区、传送、输入暂停和活动保存 |
| `src/travel/waystation.js` | 按地面高度生成驿站，避开道路与已有实体 |
| `src/travel/world-map.css` | 小窗、展开地图、小屏布局 |
| 四个场景的 `main.js` | 在物理准备后创建驿站，每帧更新标记 |

图片仅用于地图预览，实体游戏场景仍由各场景原有三维代码生成。增加区域时应同步更新地图、区域数据、加载入口、活动保存策略和实机传送测试。

## 验证

构建后运行 `node tools/world-map-check.mjs`，通过 CHROME 环境变量指定浏览器。测试四区传送、驿站落地点、活动保留、地图打开后暂停输入、关闭后继续行走、390 像素宽地图布局和浏览器错误。`WORLD_URL` 可指定公网根目录验证 GitHub Pages 子目录部署。

运行 `node tools/walk-worlds-check.mjs` 实际驱动角色完整走过八条连接道，验证同一页面内跨区、入口落地、只存在一个画布和地图、最近安全点恢复及浏览器错误。
