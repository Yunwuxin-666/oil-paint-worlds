以用户提供的天然双石拱峡谷照片为地貌和构图参考，以项目秋日森林截图为大色块油画笔触参考。保留前景巨拱、后方小拱、红砂岩岩层、蓝天负形、干旱沙地与稀疏灌木。蓝披风草帽旅人只作为人体比例锚点，构图主体为巨大的石拱和可步行的峡谷空间。

## 第五场景实现

已实现为 `?scene=arches` 的可玩区域。概念图仅用于美术参考，游戏中的石拱、峡谷和沙地均由代码生成，不加载整幅参考图作为背景墙。

- `src/arches/landscape.js`：前后两座实体岩拱、岩壁与落石，岩拱包含前后表面、内拱顶、外屋脊及两侧支撑。面片先一致细分再变形，避免非一致细分产生的裂缝；可见表面和 Rapier 三角网格碰撞来自相同几何数据。
- `src/arches/land.js`：连贯的沙地、缓坡、岩台起伏与大笔触地面；角色沿原有 1.8 米比例行走。主要石拱跨度约 110 米，后方小拱约 58 米。
- `src/arches/paint.js`：赭红、焦橙、杏黄受光面与紫褐阴影，宽笔触随岩层方向铺排；保留原角色与布料系统。
- `src/arches/environment.js`：稀疏枯草、风沙粒子和最多 48 个随时间淡去的沙地脚印。
- `src/arches/game.js`：沿路线完成岩层、巨拱腹地、后拱回望三处观察。E 观察，V 全景/跟随，R 回入口，M 地图，G 驿站；观察记录在同一标签页内跨区保存。
- 五境地图为 `public/world-map-v2.png`，生成提示词见 [地图提示词](world-map-prompt-v2.txt)。由麦田东侧的红砂风谷连接峡谷南入口；连接带更窄，避免与原先南北方向的过渡带重叠。

验收工具：`tools/arches-check.mjs` 检查封闭岩体、拱顶与岩壁碰撞、完整步行穿过双拱、观察互动、五区地图与手机布局；`tools/boundary-check.mjs` 覆盖麦田—峡谷双向通行；`tools/terrain-contact-check.mjs` 比较真实 GPU 地面深度与物理碰撞；`tools/record-arches.mjs` 录制不加速的实际行走。运行证据输出到忽略跟踪的 `shots/`。
