# 柏树麦田 · 第四场景

以用户提供的金色麦田、柏树村落绘画为构图与色彩参考；沿用项目已有的大笔触油画渲染和旅人角色。这里不对原画的准确标题、年代作认定。

## 画面拆解

| 层次 / 元素 | 参考图中的作用 | 三维实现与笔触 |
| --- | --- | --- |
| 淡奶黄天空 | 留白，衬托冷色山脊 | 天空球程序着色，低对比弧形纹理；避免满屏细噪点 |
| 三层蓝灰远山 | 冷暖对比、空间纵深 | 连续网格生成不同距离的山脊；笔触固定在世界坐标，沿坡面铺开 |
| 金黄麦田 | 主色块，起伏线条引导入村 | 真实高度场 + 弯曲田埂色带 + 立体麦丛；地面为横向宽笔触，麦秆随风倾斜 |
| 浅色小路 | 前景至村尾的游玩路线 | 从地形材质中生成弯曲道路，麦丛避让道路与建筑院落 |
| 深蓝绿柏树 | 竖向重音、村落尺度标尺 | 24 棵有实体树干的弯曲锥形树冠；纵向宽笔触；根部采样地形高度 |
| 奶油色村屋 | 中景视觉中心 | 15 栋实体建筑，石基、墙体、封闭山墙、双坡瓦顶、门窗、部分烟囱 |
| 灰绿绿篱 | 切分田块，连接房屋与地面 | 沿田埂排列连续低矮体块，竖向宽笔触；避开主路和建筑 |
| 画架与调色台 | 轻量探索玩法 | 3 处采色点 + 1 处作画点；仅在附近显示交互提示 |

## 统一风格规则

提示词基准：**大色块油画、宽扁刷厚涂、方向明确的笔触、适量露底、奶黄天空、赭金麦田、奶油石墙、陶土瓦顶、深蓝绿火焰状柏树、鼠尾草绿篱、层叠蓝灰山脊、暖光与冷色阴影、轻微画布织纹。**

笔触必须服从形体：墙面向上，屋顶顺坡，树冠纵向弯曲，麦田顺风与田坡，远山顺山势。不能靠增加微小颗粒、写实贴图或屏幕噪点冒充油画。世界中的房屋、树木、地形和远山均为代码生成的三维几何；生成图用于造型和色彩参考，不作为整幅背景平面。

## 尺度与坐标

- 单位按米处理，Y 轴向上；复用约 1.8 米的旅人，不单独放大人物模型。
- 房屋宽约 6–8.2 米，墙高约 5.2–8.2 米，门高 2.1 米。
- 柏树高 9–21 米，麦秆基础高度 0.48–0.90 米；绿篱主体约 0.7–1.2 米。
- 可行走范围约 X ±115 米、Z -105 至 112 米；外圈地形用于视野延伸。
- 地形分为前景坡肩、中部村落鞍部、背后抬升田坡；村屋地面高差约 14 米。两侧采用宽阔丘陵和弯曲田垄，避免村屋全部站在同一平面。院落整平的过渡带避开主路，主路坡度检查限制在 28° 以下。
- 每栋房屋先压平局部院落，再对完整地基足迹采样，石基下探至最低地面之下，墙体落于最高采样点。
- 房屋和树干使用实体碰撞。建筑目前为外景资产，没有室内探索。
- 默认第三人称距离 13 米、视场角 42°，保留滚轮调整和 V 键全景。

## 交互与动态

沿路探索三处调色台，按 E 获取「麦田金」「柏树绿」「远山蓝」，回到村口画架按 E 完成画作。R 清空颜色并返回起点。界面不设常驻任务侧栏。

麦丛使用风场摆动；角色进入时向外倾倒，并保留 16 个足迹采样用于逐渐恢复。它是程序化植被形变，不是逐株刚体模拟。靠近镜头的麦丛渐隐，减少遮挡人物。山体和房屋上的笔触固定在世界坐标中，镜头转动不会让整幅背景跟着移动。

## 已输出资产

打开 `/village/assets.html` 可预览与下载：柏树、村屋、麦丛、绿篱四张透明底单体参考图，以及一张完整场景概念图。准确提示词见 `public/village/assets/manifest.json`。

本轮探索使用真实生成的随机种子 **339721**，仅用于未锁定的交互构思与程序分布；用户确定的配色、参考构图职责和大笔触方向保持固定。该数值不是图像生成工具的可复现模型种子。

## 开发入口

| 文件 | 用途 |
| --- | --- |
| `src/village/config.js` | 房屋、柏树、交互点、边界、起点与道路 |
| `src/village/land.js` | 地形高度、院落整平、道路与田块笔触 |
| `src/village/landscape.js` | 程序天空、连续远山与山体笔触 |
| `src/village/props.js` | 建筑、柏树、绿篱、画架与地基 |
| `src/village/paint.js` | 本场景的调色板 |
| `src/village/environment.js` | 麦田、风、角色碰触与足迹恢复 |
| `src/village/game.js` | 采色、作画和重置状态 |
| `src/village/main.js` | 场景装配、相机、光照、物理与渲染循环 |

增加建筑时应同时维护道路净空和地基采样；修改交互点后实际走完整条路线，不能只检查目标坐标。新增色彩可在本场景调色板中调整，避免影响既有三场景。

## 验证

`pnpm run build` 构建；设置 `CHROME` 后运行 `node tools/village-check.mjs`。

检查涵盖 180 个地基边缘接地点、角色沿道路实际行走、三处采色、返回画架完成作画、重置、竖屏以及浏览器 / 着色器错误。输出截图在 `shots/village-*.png`。这是一版可游玩的三维改编，不等同于从所有视点都能逐像素复刻二维原画。
